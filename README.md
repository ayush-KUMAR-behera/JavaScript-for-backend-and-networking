# JavaScript for Backend Engineers

A structured JavaScript learning journey focused on the concepts required for **Java Backend Development**, **Frontend–Backend Communication**, and **Computer Networks**.

## 🎯 Why this Repository?

As a Java Backend Developer, I wanted to understand **how JavaScript communicates with backend APIs** instead of learning it only for frontend development.

This repository documents my daily learning with hands-on coding, interview preparation, and practical examples.

---

## 🚀 Learning Objectives

- JavaScript Fundamentals
- Modern JavaScript (ES6+)
- JavaScript Runtime & Event Loop
- Promises & Async/Await
- Fetch API
- DOM & Browser Events
- HTTP, JSON & REST APIs
- Frontend ↔ Backend Communication
- React Fundamentals
